# Paperloom

Paperloom은 변경하지 않은 영문 원문과 자동 생성된 한국어 논문을 나란히 읽는
로컬 우선 데스크톱 앱입니다. 원문 PDF는 수정하지 않습니다.

## 주요 기능

- 왼쪽 영문 원문·오른쪽 한국어 논문의 기본 병렬 보기
- 두 패널의 독립적인 페이지 이동·확대·맞춤·회전·확장
- PDF 내용 해시로 원문을 식별하고 파일 이동·이름 변경 후에도 결과 복원
- 저장된 한국어 논문이 있으면 재번역 없이 즉시 함께 열기
- 논문 전체 문맥과 용어 기준을 이용한 영문→한국어 섹션 번역
- 완료 섹션 체크포인트와 보호된 직접 수정
- 일반 논문 흐름과 원문형 그림·표·코드 플로트 배치
- 자동 무결성 검사, 패널 안 사후 수정, 안전한 교체, PDF 내보내기
- 하이라이트, 논문 메모, 문맥 단어 뜻, 그림·표 참조 미리보기
- 논문 전체 Ask 대화 기록, 근거 페이지 이동, 답변 복사·메모 저장
- 지원 모델의 원본 PDF Ask 입력과 전체 텍스트·계층형 요약 대체 경로
- OpenAI 호환 API와 선택적인 Codex/ChatGPT 로그인 연결
- 메인 화면의 모델 프로필·추론 강도 전환

한국어가 첫 버전의 유일한 번역 대상입니다. 선택 영역·현재 페이지·범위
번역, 원문 위 번역 오버레이, 패널 동기화, 수동 상하 보기, 폴더 스캔,
태그, OpenCode TOML 가져오기는 제공하지 않습니다.

## 실행

Windows에서는 저장소 루트의 `Paperloom.cmd`를 더블클릭하세요. 처음
한국어 논문을 만들 때 약 4.9MB의 한글 조판 글꼴 패키지를 한 번
설치합니다.

```bash
npm install
npm run tauri dev
```

브라우저에서 UI를 빠르게 확인하려면:

```bash
npm run dev
```

데스크톱 개발 빌드에는 Node.js 20 이상, Rust stable, Visual Studio C++
Build Tools와 WebView2가 필요합니다.

## 한국어 논문 만들기

1. `PDF 열기`로 디지털 텍스트가 포함된 영문 논문을 엽니다.
2. 오른쪽의 `한국어 논문 만들기`를 누릅니다.
3. 처음이라면 한글 조판 패키지를 자동으로 준비합니다.
4. 섹션 번역과 조판이 끝나고 무결성 검사를 통과하면 오른쪽에 바로 적용됩니다.
5. 이후 오른쪽 패널의 `내용 수정`, `다시 만들기`, `PDF 내보내기`를 사용합니다.

재생성 중에도 기존에 적용된 한국어 논문은 유지됩니다. 새 결과가
실패하거나 무결성 검사를 통과하지 못하면 기존 결과를 덮어쓰지 않습니다.

본문은 일반 논문처럼 단과 페이지를 넘어 이어집니다. 그림·표·코드는
원문의 순서, 단일/양단 폭, 크기·비율과 상단·하단·인라인 배치 역할을
유지하며, 한국어 분량에 따라 페이지 번호는 달라질 수 있습니다.

## Ask와 원본 PDF 입력

Ask에는 범위 선택기가 없습니다. 모든 질문은 논문 전체를 배경 맥락으로
사용하고, 선택한 문장이 있으면 질문의 초점으로 자동 첨부합니다.

- `원본 PDF 질문 입력`을 명시적으로 켠 API 프로필은 첫 Ask 때 PDF
  전체 전송 범위를 알리고 업로드합니다. 같은 논문·제공자에서는 원격
  파일 ID를 재사용합니다.
- 그 외 프로필은 표지, 소속, 연락처, 참고문헌을 제외한 논문 전체
  텍스트를 사용합니다.
- 컨텍스트 한도를 넘으면 섹션별 계층형 요약을 만들고 이를 사용했다는
  사실을 답변에 표시합니다. 텍스트를 조용히 잘라내지 않습니다.
- 검증 가능한 답변 근거만 원문 페이지 링크로 제공합니다.

번역 생성은 PDF 전체가 아니라 번역 대상 본문과 캡션만 모델에
전송합니다.

## 지원 범위

- 지원: 디지털 텍스트 영문 PDF, 1단·2단 논문, 한국어 본문/초록/캡션,
  원본 그림·표·수식·코드 보존
- 제한: 스캔 PDF는 원문 열람과 지원 모델의 PDF Ask가 가능할 수 있지만
  첫 버전의 한국어 재조판 대상은 아닙니다.
- 문서 구조가 매우 비표준이면 자동 무결성 검사가 적용을 차단할 수 있습니다.

생성 PDF 첫 페이지와 메타데이터에는 비공식 번역본임을 표시합니다.
